# Política de Segurança 🔒

## Reportando vulnerabilidades

**Não abra issue pública** para questões de segurança.
Use **Security → Report a vulnerability** ou contate
[@vitorsavicki](https://github.com/vitorsavicki).

## O que este projeto exige de quem segue o guia

1. Trocar a senha padrão do OmniRoute no primeiro acesso
2. Restringir o gateway a `127.0.0.1`
3. Nunca commitar chaves — o CI (gitleaks + checagem de padrões) bloqueia
4. Usar placeholders `<...>` em toda documentação
